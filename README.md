# Экранный переводчик

Приложение для Windows 10 версии 2004 и новее / Windows 11. Выделяет текст на экране,
распознаёт его локально и показывает перевод поверх оригинала с контрастным
полупрозрачным фоном. Интерфейс использует обычные элементы Windows и системный шрифт
Windows (Segoe UI на компьютере разработки), без отдельных тем.

## Запуск

Готовая локальная сборка находится в `artifacts/app`. Запустите `ScreenTranslator.exe`;
все остальные файлы этой папки должны оставаться рядом с ним. Для этой сборки нужен
.NET 10 Desktop Runtime, уже установленный на компьютере разработки.

1. Выберите язык назначения. По умолчанию — русский, переводчик — Google.
2. Нажмите **Сохранить**.
3. В любом приложении нажмите **Ctrl + Alt + T** и выделите область мышью.
4. Дождитесь перевода. Оверлей пропускает клики в исходное приложение.
5. **Esc** или повторная горячая клавиша убирает перевод. Следующее нажатие запускает новый захват.

Внизу окна есть две отдельные кнопки: **«Выделить область»** и **«Весь экран»**.
Вторая сразу переводит монитор, на котором открыт курсор, без выделения.
Кнопки сохраняют настройки, но не меняют выбранный режим горячей клавиши;
по умолчанию горячая клавиша предлагает выделить область.
Во время обработки горячая клавиша отменяет операцию. При выделении область можно отменить
правой кнопкой мыши или Esc. Если Esc занят другим приложением, используйте горячую клавишу
или пункт «Убрать перевод» в меню трея.

По умолчанию закрытие окна оставляет приложение в трее. Двойной клик по значку открывает
настройки, пункт «Выход» полностью завершает работу. Это поведение можно отключить.

## Настройки

- **Перевод:** язык, Google/Яндекс, автоматическое переключение на другой сервис при ошибке,
  выделение области / монитор под курсором / последняя выделенная область, горячая клавиша и поведение закрытия.
- **Оверлей:** семейство и жирность шрифта, ручной размер или диапазон автоматического размера,
  цвета текста/фона, непрозрачность фона, отступы, выравнивание, время показа. Есть живой предпросмотр.
- **Распознавание:** автоматический выбор среди установленных языков OCR либо конкретный язык,
  увеличение изображения ×1–×3, объединение соседних строк в абзацы.

Исходный язык переводчик определяет сам. Автоматический выбор OCR сравнивает результаты
доступных языковых моделей по количеству распознанного текста; при смешанных языках или
ошибках задайте язык OCR вручную. Для новых языков установите компонент «Оптическое
распознавание символов» в языковых параметрах Windows. Приложение не скачивает модели само.
На компьютере разработки проверены установленные модели `ru` и `en-US`.

Настройки сохраняются в `%LOCALAPPDATA%/ScreenTranslator/settings.json`.
Предыдущая исправная версия хранится в `settings.json.bak`; повреждённый файл при
последующей записи сохраняется как `settings.json.damaged`.

## Перевод и ограничения

Способ получения временного ключа Google и SID Яндекса адаптирован из
[Traduzir-paginas-web](https://github.com/FilipePS/Traduzir-paginas-web).
Личные API-ключи не нужны. Авторизация хранится только в памяти до 20 минут;
ответы перевода — до 30 минут, с ограничением размера кеша. Запросы отправляются пакетами.
При отказе авторизации ключ обновляется с одним повтором; недоступное получение ключа
имеет короткую паузу перед следующим запросом. Полученный ключ не зашит в исходный код.

Это веб-интерфейсы сервисов, и они могут менять формат или ограничивать доступ.
Во время проверки 5 октября 2026 года Google выполнил реальный перевод; Яндекс вернул
HTTP 429 при получении SID. Приложение сообщает об ограничении и, при включённом резервном
переводчике, переключается на Google. Переключение работает в обе стороны.

Снимки остаются в оперативной памяти. В интернет отправляется распознанный текст;
для перевода необходимо подключение. OCR и перевод запускаются только по команде,
без постоянного наблюдения за экраном. Оверлей относится к снимку: после прокрутки или
перемещения исходного окна следует убрать его и запустить перевод заново.
Если длинный перевод не помещается даже при минимальном размере, показывается многоточие
и сообщение с числом таких блоков. Уменьшите размер шрифта/отступы или выбирайте более широкую область.
Защищённые окна и некоторые игры в эксклюзивном полноэкранном режиме могут не захватываться;
для игр используйте оконный режим или окно без рамки.

Windows OCR API возвращает слова и их координаты; используются установленные языковые пакеты
([документация Microsoft](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr.ocrengine)).
Прозрачность фона реализована через layered window с альфа-каналом
([UpdateLayeredWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-updatelayeredwindow)).

## Сборка и проверки

Требуется Windows и .NET 10 SDK. Откройте `simplePC_screen_translate/simplePC_screen_translate.slnx`
в Visual Studio либо выполните из корня:

```powershell
dotnet restore simplePC_screen_translate/simplePC_screen_translate.slnx
dotnet build simplePC_screen_translate/simplePC_screen_translate.slnx -c Release --no-restore
dotnet run --project simplePC_screen_translate/ScreenTranslator.Tests -c Release --no-restore
dotnet run --project simplePC_screen_translate/ScreenTranslator.Tests -c Release --no-restore -- --live-only
dotnet publish simplePC_screen_translate/simplePC_screen_translate -c Release --no-restore -o artifacts/app
```

При недоступном nuget.org используйте официальный источник Microsoft, указанный в `AGENTS.md`.
Автоматические проверки покрывают сохранение/восстановление настроек, форматы ключей и ответов,
обновление истёкшей авторизации, кеш, дедупликацию, резервный сервис, ограничение размера Unicode-запросов,
отмену, геометрию абзацев, прозрачность, Win32-оверлей, конфликты клавиш и реальный OCR.
Изображения всех вкладок и оверлея сохраняются в `artifacts/checks` для просмотра.

Уведомления об исходном проекте и лицензии: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
