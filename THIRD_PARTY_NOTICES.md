# Сторонние компоненты

## Traduzir-paginas-web

Получение временного ключа Google, SID Яндекса и форматы веб-запросов адаптированы из
`src/background/translationService.js` проекта
[Traduzir-paginas-web](https://github.com/FilipePS/Traduzir-paginas-web), FilipePS и участники проекта.
Для адаптации использовалась локальная копия пользователя с изменениями из
[xanstar6067/Traduzir-paginas-web](https://github.com/xanstar6067/Traduzir-paginas-web).

Файл `simplePC_screen_translate/simplePC_screen_translate/Services/WebTranslationClient.cs`
распространяется на условиях Mozilla Public License 2.0. Текст лицензии находится в
[licenses/MPL-2.0.txt](licenses/MPL-2.0.txt). При распространении исполняемой версии
сохраните это уведомление и предоставьте исходный код этого файла, включая изменения,
в соответствии с MPL 2.0. Остальные файлы приложения написаны отдельно.

## Windows SDK и .NET

Приложение использует .NET, Windows Forms и Windows Media OCR Microsoft.
Их условия поставляются с соответствующими компонентами Microsoft.
